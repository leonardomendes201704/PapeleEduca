API do robô (IA)

Endpoint para criar posts automaticamente. Sempre salva como Rascunho.

POST /api/blog/posts

Header: X-API-Key: <BLOG_API_KEY>

Body JSON mínimo: {"title":"...","content_html":"..."}

Campos opcionais: excerpt, slug, category, tags[], cover_url, seo_title, seo_description, author_name.
